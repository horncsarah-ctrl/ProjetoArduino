# 🤖 Projeto Arduino

Este repositório reúne projetos desenvolvidos com Arduino durante meus estudos em eletrônica e programação embarcada, explorando a integração entre hardware e software por meio de aplicações práticas.

## 📖 Sobre

Este projeto foi criado com o objetivo de colocar em prática conceitos de programação embarcada utilizando a plataforma Arduino. Ao longo do desenvolvimento, foram explorados componentes eletrônicos, sensores, atuadores e a lógica necessária para controlar dispositivos físicos.

Além de aprimorar minhas habilidades de programação, este repositório representa meu aprendizado na interação entre software e hardware, reforçando conceitos como automação, leitura de sensores e controle de sistemas embarcados.

## ✨ O que você encontrará

* Projetos utilizando Arduino;
* Controle de componentes eletrônicos;
* Integração com sensores e atuadores;
* Exemplos de automação;
* Aplicações práticas para estudo e aprendizado.

> Novos projetos poderão ser adicionados conforme avanço nos estudos da plataforma Arduino.

## 🛠️ Tecnologias utilizadas

* Arduino
* Linguagem C/C++ (Arduino)
* Arduino IDE

> Dependendo do projeto, podem ser utilizadas bibliotecas específicas e diferentes módulos eletrônicos.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/horncsarah-ctrl/ProjetoArduino.git
```

Entre na pasta:

```bash
cd ProjetoArduino
```

Abra o projeto desejado na **Arduino IDE**, conecte a placa Arduino e realize o upload do código para iniciar os testes.

## 🎯 Objetivos

Este repositório tem como finalidade:

* praticar programação para sistemas embarcados;
* compreender o funcionamento da plataforma Arduino;
* desenvolver projetos envolvendo hardware e software;
* aprender a utilizar sensores, módulos e atuadores;
* documentar minha evolução na área de eletrônica e automação.

## 🌱 Evolução

Os projetos presentes neste repositório foram desenvolvidos em diferentes momentos da minha jornada de aprendizado. Por esse motivo, é possível observar diferenças na complexidade, organização e implementação entre eles, refletindo minha evolução ao longo do tempo.
